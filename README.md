# Brew & Bite Cafe - Simple Backend

This is a simple Node.js backend.

## Files
- index.html : Your original website
- server.js : Backend server
- script.js : Connects reservation form with backend
- reservations.json : Stores reservation data
- package.json : Node.js package file

## How to run

1. Open this folder in VS Code.
2. Open Terminal.
3. Run:

npm install

4. Then run:

npm start

5. Open browser:

http://localhost:3000

## How it works

Customer fills the Book a Table form
        ↓
Form sends data to server.js
        ↓
server.js saves data
        ↓
reservations.json
